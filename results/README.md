# Results

Written automatically by the pipeline: one folder per case (real organisations appear here after you run them), one file per stage
(`01_intake.json` ... `06_manifest.json`), plus the assessment file `06_assessment.html` / `.pdf`, `06_evidence.csv`
and the Word templates. `_llm_cache/` holds cached LLM responses when the LLM providers are on.
See the main README for what each file contains. Safe to delete; re-run the pipeline to regenerate.

Every file here is prepared by the **AI agent** and marked "not yet reviewed" (see the `provenance`
block in each JSON file, the "Who prepared this" box in the report, and the "Filled by" column in the
Word forms). Only `07_review.json`, written by the review screen, is a **Water Care staff** record.
